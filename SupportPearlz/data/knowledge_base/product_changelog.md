# Product Changelog and Release Notes
Version: 2026.4
Last updated: 2026-06-12
Doc type: release_notes
Product lines: AquaPearl 500 Pro, AeroPearl Mini

## AquaPearl 500 Pro firmware 2.4 — 2026-05-22
Firmware 2.4 improved communication diagnostics and changed the wording displayed for E-06. The meaning of E-03 remains sediment pre-filter saturation. The reset sequence for E-03 remains a five-second RESET hold after filter replacement.

## AquaPearl 500 Pro firmware 2.3 — 2026-03-14
Improved filter-status estimation and reduced false maintenance notifications. No warranty terms were changed.

## AeroPearl Mini app release 3.1 — 2026-05-02
Improved pairing instructions and added clearer connection-status messages.

## Documentation versioning
Release notes are not a substitute for current product manuals or policy documents. When a release note changes a diagnostic wording, use the current troubleshooting guide for the operational remedy.

## Deliberate version seam
A search result that mentions an older E-06 phrase should not override the current 2.4 diagnostic wording. The E-03 meaning is unchanged across the releases documented here.
