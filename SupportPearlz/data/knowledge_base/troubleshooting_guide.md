# AquaPearl Troubleshooting Guide
Version: 2026.4
Last updated: 2026-06-12
Doc type: guide
Product line: AquaPearl 500 Pro

## Alert and symptom table
| Symptom | Probable cause | Action |
|---|---|---|
| No power | Socket, adapter, or internal power fault | Check socket and power connection. If still dead, contact support. |
| Low flow | Saturated filter or low inlet pressure | Check pressure and filter status; replace filter if indicated. |
| Leaking base | Loose connection or damaged seal | Turn off water and contact service if tightening the accessible connection does not stop the leak. |
| Bad taste after filter change | Insufficient first-run flush | Repeat the first-run flushing procedure from the Installation Guide. |
| Continuous running | Flow sensor or inlet condition | Turn off water if the unit runs continuously and contact support. |
| Three short beeps | E-03 filter saturation alert | Replace the sediment pre-filter and hold RESET for five seconds. |
| Blinking red LED | Active alert condition | Read the displayed alert code and follow the corresponding table entry. |
| High TDS reading | Source-water condition or sensor issue | Verify source water and repeat measurement; escalate if persistent. |
| Noisy pump | Air in line or pump fault | Check inlet connection; if noise persists, stop use and contact support. |
| App will not pair | Bluetooth/Wi-Fi setup issue | Restart pairing mode and confirm the mobile app is updated. |
| Water flow stops | Empty tank or inlet interruption | Check inlet supply and tank status. |
| Unit will not reset | Button sequence not completed | Hold RESET for the duration specified for the alert. |
| Red and amber lights alternate | Maintenance alert | Review filter and maintenance status. |
| Repeated E-03 after filter replacement | Incorrect cartridge or sensor condition | Confirm the correct cartridge SKU; escalate if alert remains. |
| Water temperature feels unusual | Input water condition | Check source water and installation environment; do not modify internal controls. |
| Cracked housing | Physical damage | Stop use if leaking and contact support; do not attempt structural repair. |

## Audible codes
E-01 indicates an inlet-water interruption. E-02 indicates a flow sensor anomaly. E-03 indicates sediment pre-filter saturation. E-04 indicates pump protection. E-05 indicates an over-temperature condition. E-06 indicates a communication fault. E-07 indicates a tank-level sensor anomaly. E-08 indicates a service-required condition.

## Escalation criteria
Customers must not open electrical compartments, bypass safety controls, repair circuit boards, or disassemble the pump. Persistent leaks near electrical components, burning smells, smoke, repeated pump protection alerts, or exposed wiring require immediate shutdown and human service escalation.

## Version note
Firmware 2.4 changed the E-06 communication diagnostic wording but did not change the E-03 filter-saturation meaning.

## 21. Common customer phrasing
Customers may describe E-03 without using the code. Phrases such as "three beeps", "beeps three times", "red light after the beeps", or "filter alarm" should be mapped through semantic retrieval to the documented E-03 content. Retrieval should still verify the product line because other products can have different indicators.

## 22. Model identification
Before applying model-specific instructions, identify the product line from the customer's wording or ask a clarifying question when necessary. The assistant must not silently apply AquaPearl 500 Pro procedures to AeroPearl Mini or a discontinued model.

## 23. Price interpretation
Pricing answers should identify the SKU and distinguish list price from current promotional price. If multiple filters match the word "filter", the assistant should list the relevant options or ask which product line the customer owns.

## 24. Policy interpretation
Policy answers should quote or paraphrase only the applicable rule. If a question combines return, warranty, delivery, and service terms, retrieval may need several sources. The assistant should separate each rule instead of blending them into a new policy.

## 25. Unsupported commitments
The system must never invent a phone number, discount percentage, refund amount, delivery exception, certification, or service booking. When the knowledge base is silent, the response should use the documented escalation route.

## 26. Evaluation examples
A good evaluation question tests a known fact, a cross-document seam, a follow-up, an unanswerable gap, an ambiguity, or an adversarial instruction. The expected source should be identified before running the model so retrieval can be scored independently.

## 27. Human verification
Source citations are intended to let a support agent inspect the evidence. A citation is not permission for the model to make a claim that the cited passage does not support.
